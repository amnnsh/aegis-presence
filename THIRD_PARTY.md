## Installed packages

The application declares Next.js 16.3.8, React/ReactDOM 19.3.0, MediaPipe Tasks Vision 0.10.35, and Transformers.js 3.8.1. Development dependencies include TypeScript, Tailwind CSS, Node/React type declarations, and Playwright. Exact transitive resolutions must be recorded in the lockfile generated by the team's first successful installation. Review each installed package's LICENSE and notices; keep required notices when redistributing compiled code.

Primary repositories / documentation:

- Next.js: https://github.com/vercel/next.js
- React: https://github.com/facebook/react
- Tailwind CSS: https://github.com/tailwindlabs/tailwindcss
- TypeScript: https://github.com/microsoft/TypeScript

The project intentionally keeps a known MediaPipe API version rather than silently loading a CDN's `latest` tag. Pinning a version is not a vulnerability audit. Check advisories and licenses before changing or shipping dependencies.

## Face-landmark model and WASM

`scripts/prepare-assets.mjs` copies WASM from the installed MediaPipe npm package and downloads this versioned model at install/build time:

https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task

Guide: https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker/web_js

The archive does not include the model weights or WASM binaries. They are generated locally and ignored by Git. The model/package retain their own upstream terms; do not infer that a documentation page's text/code license automatically licenses every model asset. Review the applicable model terms and intended-use guidance before redistribution or production use. This project does not claim to have completed that legal review.

The asset script prints a SHA-256 for traceability, but no independently authenticated upstream digest is bundled. That printout alone does not prove supply-chain integrity. A production release should verify and record approved artifact digests and provenance before deployment.

## Speech model and ONNX runtime

The optional spoken-digit check uses Transformers.js (`@huggingface/transformers` 3.8.1, Apache-2.0, https://github.com/huggingface/transformers.js), which bundles ONNX Runtime Web (MIT, https://github.com/microsoft/onnxruntime).

`scripts/prepare-assets.mjs` copies the runtime's `ort-wasm-simd-threaded.jsep` files from the installed package into `public/ort/` and downloads the 8-bit quantized Whisper tiny English model into `public/models/whisper/` from one pinned revision:

https://huggingface.co/onnx-community/whisper-tiny.en/tree/2575352d61be1bf7225cf8f8b268a4678025fc58

It is an ONNX conversion of OpenAI's `whisper-tiny.en`, whose model card lists Apache-2.0 (https://huggingface.co/openai/whisper-tiny.en). The `onnx-community` repository itself declared no license field when this was written; confirm the terms before redistribution. The two weight files are checked against the SHA-256 values the hub publishes for that revision. That detects a corrupted or swapped download; it is not an independent audit of the weights.

The model and runtime are generated locally, ignored by Git, and served from the site's own origin. The browser never contacts a model hub, and no audio leaves the device.
