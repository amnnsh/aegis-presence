The MIT license at the root covers this project's original source and documents. It does not replace third-party licenses, source attribution, trademarks, hosted-service terms, or model terms.

## Installed packages

The application declares Next.js 16.3.8, React/ReactDOM 19.3.0, and MediaPipe Tasks Vision 0.10.35. Development dependencies include TypeScript, Tailwind CSS, Node/React type declarations, and Playwright. Exact transitive resolutions must be recorded in the lockfile generated by the team's first successful installation. Review each installed package's LICENSE and notices; keep required notices when redistributing compiled code.

Primary repositories / documentation:

- Next.js: https://github.com/vercel/next.js
- React: https://github.com/facebook/react
- Tailwind CSS: https://github.com/tailwindlabs/tailwindcss
- TypeScript: https://github.com/microsoft/TypeScript
- MediaPipe: https://github.com/google-ai-edge/mediapipe
- Playwright: https://github.com/microsoft/playwright

The project intentionally keeps a known MediaPipe API version rather than silently loading a CDN's `latest` tag. Pinning a version is not a vulnerability audit. Check advisories and licenses before changing or shipping dependencies.

## Face-landmark model and WASM

`scripts/prepare-assets.mjs` copies WASM from the installed MediaPipe npm package and downloads this versioned model at install/build time:

https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task

Guide: https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker/web_js

The archive does not include the model weights or WASM binaries. They are generated locally and ignored by Git. The model/package retain their own upstream terms; do not infer that a documentation page's text/code license automatically licenses every model asset. Review the applicable model terms and intended-use guidance before redistribution or production use. This project does not claim to have completed that legal review.

The asset script prints a SHA-256 for traceability, but no independently authenticated upstream digest is bundled. That printout alone does not prove supply-chain integrity. A production release should verify and record approved artifact digests and provenance before deployment.
